# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-22

### Added

- `Catalog` with locale-keyed messages, an active locale and a fallback locale
  (`en` by default), ported from the Go `i18n.Catalog`.
- `Catalog::t` (returns the key when missing), `Catalog::tf` (formatted
  lookup), `Catalog::has`, `Catalog::locales`, `Catalog::add_locale`,
  `Catalog::set_locale`, `Catalog::set_fallback` and `Catalog::locale`.
- `Catalog::load_json` for `{ "locale": { "key": "text" } }` files, with the
  `Error::Read` and `Error::Decode` error variants.
- `detect_locale`: checks `LC_ALL`, `LC_MESSAGES` and `LANG`, normalizing
  `pt_BR.UTF-8` to `pt-BR`.
- `format::sprintf`: printf-style formatter reproducing Go's `fmt.Sprintf`
  diagnostics (`%!d(MISSING)`, `%!s(int=42)`, `%!(EXTRA ...)`), plus `{}`
  placeholders.
- Golden file `tests/golden/i18n.txt` generated by the Go implementation,
  verified by `tests/parity.rs`.

### Known differences

- `Catalog::t` takes the key with the same lifetime as `&self` so it can be
  returned unchanged when missing.
- `Catalog::has` only checks the active locale, as the Go implementation does.
- `Catalog::tf` takes `serde_json::Value` arguments. JSON cannot distinguish
  Go's `int` from `int64`, nor `float32` from `float64`, and cannot represent
  `NaN` or infinities.
- `format::sprintf` also accepts `{}` placeholders and `{{`/`}}` escapes.
  Go prints `{{` literally, so templates containing doubled braces render
  differently.
- Verbs not listed in the `sprintf` documentation (for example `%c`, `%T`,
  `%g`, `%p` and `*` widths) are reported as `%!verb(...)` instead of being
  formatted.
- The precision of a mismatched argument is not applied to the reported
  value: Go prints `%!f(int=03)` for `%.2f` with `3`, this port prints
  `%!f(int=3)`.
- `%q` escapes control characters but not every non-printable Unicode code
  point.
- `detect_locale` does not change the case of the language or region, like
  the Go implementation.
- Error messages are in English.
- Thread safety: `&self` methods can be shared across threads; mutation
  requires `&mut self`, so the Go mutex is not needed.
