# charm-nav

> [Read in Portuguese](README.pt-br.md)

Navigation components for terminal UIs, styled with
[lipgloss](https://crates.io/crates/lipgloss).

This crate is a Rust port of the Go library
[`github.com/junhinhow/charm-nav`](https://github.com/junhinhow/charm-nav) and
reproduces its rendering and behaviour. Its output is checked against golden
files generated by the Go original.

## Components

### Tabs

Horizontal tab bar with active/inactive styling and configurable separators.

```rust
use charm_nav::Tabs;

let mut tabs = Tabs::new(&["Home", "Settings", "About"]);
tabs.next();
println!("{}", tabs.render());
// Home | Settings | About
//         ^^^^^^^^ (active, bold + underline)
```

**API:**

| Method | Description |
|--------|-------------|
| `Tabs::new(items)` | Create a new tab bar |
| `set_active(index)` | Set the active tab by index (out of range values are ignored) |
| `next()` | Move to the next tab (wraps around) |
| `previous()` | Move to the previous tab (wraps around) |
| `active()` | Get the active tab index |
| `items()` | Get all tab labels |
| `add(items)` | Append tabs; returns the index of the first one added, or `None` when `items` is empty |
| `remove(index)` | Remove the tab at `index`; returns its label (empty string when the index is invalid) |
| `render()` | Render the styled tab bar |

**Customizable fields:** `separator`, `active_style`, `inactive_style`

---

### Breadcrumb

Trail navigation with a push/pop stack and a configurable separator.

```rust
use charm_nav::Breadcrumb;

let mut breadcrumb = Breadcrumb::new(&["Home", "Settings"]);
breadcrumb.push("Profile");
println!("{}", breadcrumb.render());
// Home > Settings > Profile
//                    ^^^^^^^ (active, bold)
```

**API:**

| Method | Description |
|--------|-------------|
| `Breadcrumb::new(items)` | Create a new breadcrumb trail |
| `push(item)` | Append an item |
| `pop()` | Remove and return the last item (empty string when empty) |
| `items()` | Get all breadcrumb items |
| `add(items)` | Append items; returns the index of the first one added, or `None` when `items` is empty |
| `remove(index)` | Remove the item at `index`; returns its label (empty string when the index is invalid) |
| `render()` | Render the styled breadcrumb |

**Customizable fields:** `separator`, `active_style`, `inactive_style`

---

### Sidebar

Vertical menu with a cursor indicator and a selection highlight.

```rust
use charm_nav::Sidebar;

let mut sidebar = Sidebar::new(&["Dashboard", "Users", "Settings", "Logs"]);
sidebar.set_selected(1);
println!("{}", sidebar.render());
//   Dashboard
// ▸ Users        (selected, highlighted)
//   Settings
//   Logs
```

**API:**

| Method | Description |
|--------|-------------|
| `Sidebar::new(items)` | Create a new sidebar menu |
| `set_selected(index)` | Set the selected item by index (out of range values are ignored) |
| `next()` | Move to the next item (wraps around) |
| `previous()` | Move to the previous item (wraps around) |
| `selected()` | Get the selected item index |
| `items()` | Get all menu items |
| `add(items)` | Append items; returns the index of the first one added, or `None` when `items` is empty |
| `remove(index)` | Remove the item at `index`; returns its label (empty string when the index is invalid) |
| `render()` | Render the styled sidebar |

**Customizable fields:** `width`, `cursor`, `selected_style`, `unselected_style`

**Rendering rules:**

- The cursor is measured in **display columns**, not bytes. `"▸ "` is 2 columns
  wide even though it is 4 bytes long, so every item stays aligned.
- Items that do not fit in `width` are **truncated**, never wrapped, so a long
  label can never push the menu out of the terminal.
- The selection highlight covers the **entire line width**, not just the text.
- `width` is measured in columns. Zero is rendered as one column.
- `remove` keeps the selection consistent: removing an item before the selected
  one keeps the same item selected, and removing the selected item moves the
  selection to the next one.

## Default styles

| Component | Style | Value |
|-----------|-------|-------|
| Tabs | `active_style` | bold, underline, foreground `#7D56F4` |
| Tabs | `inactive_style` | foreground `#666666` |
| Tabs | `separator` | `" \| "` |
| Breadcrumb | `active_style` | bold, foreground `#7D56F4` |
| Breadcrumb | `inactive_style` | foreground `#666666` |
| Breadcrumb | `separator` | `" > "` |
| Sidebar | `selected_style` | bold, foreground `#7D56F4`, background `#1A1A2E` |
| Sidebar | `unselected_style` | foreground `#666666` |
| Sidebar | `width` | `20` |
| Sidebar | `cursor` | `"▸ "` |

## Parity with the Go original

The golden file `tests/golden/nav.txt` is generated by the Go program in
`reference/go/charm-nav/cmd/parity`. It covers navigation, out of range indexes,
`add` and `remove` on each component, custom width and cursor, truncation, the
minimum width and an empty cursor. The comparison removes ANSI codes and
trailing spaces on both sides.

```bash
cargo run -p charm-parity --bin parity -- gen \
    crates/charm-nav/tests/golden/nav.txt -- \
    go run ./reference/go/charm-nav/cmd/parity

cargo test -p charm-nav
```

## Known differences

| Go | Rust |
|----|------|
| `Add(items ...string) int` returns `-1` when nothing is added | `add(&[&str]) -> Option<usize>` returns `None` |
| `Items()` returns a copy | `items()` returns a borrowed `&[String]`, which cannot change the component |
| `Width` is an `int` | `width` is a `usize`, so negative widths cannot be expressed. Zero is rendered as one column, as in Go |
| `Remove(index int)` accepts negative indexes | `remove(index: usize)` has no negative indexes. Invalid indexes return an empty string, as in Go |
