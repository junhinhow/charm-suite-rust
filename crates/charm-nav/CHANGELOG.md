# Changelog

All notable changes to this crate are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `add` and `remove` on `Tabs`, `Sidebar` and `Breadcrumb`, mirroring the Go
  methods. `remove` keeps the active tab or the selected item consistent.
- Parity coverage for `add`, `remove`, truncation, the minimum width and an empty
  cursor, generated by `reference/go/charm-nav/cmd/parity`.

### Changed

- `Sidebar` measures the cursor in display columns, as in Go. Previously it was
  measured in bytes, which misaligned the items when the cursor was multibyte.
- `Sidebar` renders every line at exactly `width` columns, without the outer
  container. The highlight of the selected item covers the whole line.
- `Sidebar` truncates items that do not fit in `width`, instead of letting them
  overflow.

### Fixed

- Items aligned with a multibyte cursor such as `"▸ "` are no longer shifted two
  columns to the left.

## [0.1.0]

### Added

- `Tabs` component with the `set_active`, `active`, `next`, `previous`, `items`
  and `render` methods.
- `Sidebar` component with the `set_selected`, `selected`, `next`, `previous`,
  `items` and `render` methods.
- `Breadcrumb` component with the `push`, `pop`, `items` and `render` methods.
- Default separators (`" | "` and `" > "`), default cursor (`"▸ "`), default
  width (`20`) and the default active/inactive styles, identical to the Go
  original.
- Parity golden files generated by the Go original
  (`reference/go/charm-nav/cmd/parity`).
- English and Portuguese (`pt-BR`) documentation.
