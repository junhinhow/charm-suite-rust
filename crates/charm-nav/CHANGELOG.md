# Changelog

All notable changes to this crate are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0]

### Added

- `Tabs` component with the `set_active`, `active`, `next`, `previous`, `items`
  and `render` methods.
- `Sidebar` component with the `set_selected`, `selected`, `next`, `previous`,
  `items` and `render` methods.
- `Breadcrumb` component with the `push`, `pop`, `items` and `render` methods.
- Default separators (`" | "` and `" > "`), default cursor (`"▸ "`), default
  width (`20`) and the default active/inactive styles, identical to the Go
  original.
- Parity golden files generated by the Go original
  (`reference/go/charm-nav/cmd/parity`).
- English and Portuguese (`pt-BR`) documentation.
