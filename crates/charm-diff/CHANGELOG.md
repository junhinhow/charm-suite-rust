# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `Algorithm::{Lcs, Myers}` selection in `Options`; LCS remains the default for
  Go output parity, while Myers computes a shortest edit script with linear
  auxiliary memory.

## [0.1.0] - 2026-10-22

### Added

- `unified_diff` and `unified_diff_with_options`: unified diff rendering with
  `@@ -a,b +c,d @@` hunk headers and line numbers.
- `side_by_side_diff` and `side_by_side_diff_with_options`: two-column diff
  rendering for any terminal width.
- `Options` with `context_lines` (default `3`) and `style`.
- `DiffStyle` with `DiffStyle::github()`, `DiffStyle::terminal()` and
  `DiffStyle::default()`, built on top of `lipgloss::Style`.
- LCS-based diff engine, hunk building with context lines and overlapping hunk
  merging, ported line by line from the Go original
  (`github.com/junhinhow/charm-diff`).
- Golden file `tests/golden/diff.txt` generated by the Go implementation with 20
  samples, verified by `tests/parity.rs`.

### Known differences

- Column truncation counts bytes (like the Go original) instead of characters;
  broken UTF-8 sequences are replaced by `U+FFFD` in both implementations.
- ANSI escape sequences are always emitted, while the Go implementation only
  emits colours when stdout is a TTY.
