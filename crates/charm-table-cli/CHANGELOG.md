## [0.1.0]

### Added

- The `charm-table` binary, a port of the Go `charm-table-cli` command.
- Flags `--style` (`rounded`, `thick`, `double`, `ascii`), `--header` /
  `--no-header`, `--max-width`, `--color` (ANSI index or hex) and the optional
  input file argument. Without a file, the input is read from stdin.
- Input detection: JSON array, JSON Lines, and delimited text (tab when the
  first line has a tab, comma otherwise), as in the Go original.
- Go-compatible value formatting: `%g` for floats, integers without a decimal
  point, and compact JSON with sorted keys for nested values.
- Parity golden file generated by the Go program
  (`reference/go/charm-table-cli/cmd/parity`) and integration tests for the
  binary, covering every border style, `--no-header`, `--max-width`, `--color`,
  and the error paths.
- Runnable demo in `examples/charm_table_cli_demo.rs`.
- English and Portuguese (`pt-BR`) documentation, including the list of known
  differences from the Go original.
