# Changelog

All notable changes to this crate are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0]

### Added

- `Store<T>` with `new`, `get`, `set`, `update`, `subscribe`, `notify`, `undo`,
  `redo`, `can_undo`, `can_redo`, `history`, `set_history_limit`, `snapshot`
  and `restore`, mirroring the Go `Store[T]`.
- `select(&source, f)`, the derived store that only notifies when the mapped
  value changes (Go `Select`).
- `Codec` trait and `JsonCodec` (Go `Codec` and `JSONCodec`), based on `serde`.
- `Error` with `Snapshot` and `Restore` variants, carrying the codec error as
  its source.
- Behavioural tests ported from the Go suite (`tests/behavior.rs`), including
  the concurrency test.
- Parity golden file `tests/golden/store.txt`, generated by
  `reference/go/charm-store/cmd/parity`.
- Runnable demo in `examples/charm_store_demo.rs`.
- English and Portuguese (`pt-BR`) documentation.
