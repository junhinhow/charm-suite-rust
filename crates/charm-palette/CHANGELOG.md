# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-10-22

### Added

* `show_palette`: colored swatches with their hexadecimal value below.
* `show_ansi256`: the 256 ANSI colors in a grid (standard colors, color cube
  and grayscale ramp).
* `show_true_color`: a true-color rainbow gradient.
* `show_theme`: a named theme with its named colors.
* `compare_themes`: several themes rendered side by side.
* Parity test suite backed by golden files generated by the original Go
  implementation (`reference/go/charm-palette/cmd/parity`).
* Runnable example (`cargo run -p charm-palette --example demo`).
