# Changelog

All notable changes to this crate are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `Toast::id` and `Toast::with_id`. `ToastManager::add` generates an identifier
  (`toast-N`) when the toast has none.
- `Toast::persistent`, `Toast::expires_at` and the `ExpiredMsg` struct.
- `ToastManager::max_visible`, `set_max_visible`, `toasts` / `toasts_at`,
  `remove`, `update`, `next_expiry` / `next_expiry_at`, `tick_delay` /
  `tick_delay_at`, `expired_ids` / `expired_ids_at`, `expired_msg` /
  `expired_msg_at`. They mirror the Go `Toasts`, `Remove`, `Update`,
  `NextExpiry`, `Tick` and `ExpiredMsg`.
- Parity coverage for truncation at widths 2, 5, 12 and 24, persistent toasts,
  `toasts`, `update` and `remove`, generated by `reference/go/charm-toast/cmd/parity`.

### Changed

- Zero `duration` makes the toast persistent: it never expires. Previously it
  expired at once.
- `ToastManager::render` shows the newest toast first, as in Go. It showed the
  oldest first.
- `max_visible` is no longer a public field. Use `max_visible()` and
  `set_max_visible(n)`. Zero removes the limit, as in Go; before, zero rendered
  nothing.
- `ToastManager::add` keeps the `created_at` set by the caller, as in Go.
  Previously it always set it to now.
- `Toast::render(width)` truncates the message so the box never exceeds `width`,
  as in Go. Previously a long message could overflow the width.
- `ToastManager::render` takes `&self`, so it does not remove expired toasts. It
  hides them; call `cleanup` to remove them.

### Removed

- The public `max_visible` field (replaced by the accessors above).

## [0.1.0]

### Added

- `ToastType` enum (`Info`, `Success`, `Warning`, `Error`) with `label`,
  `icon` and `color`, plus a `Display` implementation matching the Go `String()`.
- `Toast` struct with the public fields `message`, `duration`, `r#type` and
  `created_at`, and the builders `new`, `with_type`, `with_message`,
  `with_duration` and `with_created_at`.
- Expiry through `is_expired` / `remaining`, and their deterministic `_at`
  variants that take the current `Instant`.
- `Toast::render`, with the same layout and colors as the Go original.
- `ToastManager` with `max_visible` (default `5`), `add`, `add_info`,
  `add_success`, `add_warning`, `add_error`, `cleanup`, `count`, `clear` and
  `render`, plus the `_at` variants `add_at`, `cleanup_at`, `count_at` and
  `render_at`.
- Golden-file parity tests generated by the Go original
  (`reference/go/charm-toast/cmd/parity`).
- Runnable demo in `examples/charm_toast_demo.rs`.
- English and Portuguese (`pt-BR`) documentation.
