## [0.1.0] - 2026-10-22

### Added

- `darken`, `lighten`, `blend`, `contrast`, `complementary` and `palette`,
  reproducing the Go `charm-color` behavior bit-for-bit (including the
  truncation/rounding rules and the premultiplied alpha handling).
- `from_lipgloss` convenience helper for parsing lipgloss color strings.
- Re-export of the canonical `charm_core::Rgb` type.
- Golden file (`tests/golden/color_ops.txt`) generated by the original Go
  implementation, checked byte-for-byte by `tests/parity.rs`.
- Unit tests ported one-to-one from the Go `color_test.go`.
