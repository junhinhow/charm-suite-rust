## [0.1.0] - 2026-10-22

### Added

* `Sparkline`: compact line chart rendered with Unicode block characters,
  with automatic resampling, multi-row rendering (1-8 rows) and an optional
  label.
* `BarChart`: horizontal and vertical bar charts with labels, numeric values,
  configurable bar thickness and per-element styles.
* `ProgressBar`: horizontal progress bar with an optional label, percentage
  display and custom fill/empty characters.
* Parity test suite backed by golden files generated by the original Go
  implementation (`reference/go/charm-charts/cmd/parity`).
* Runnable example (`cargo run -p charm-charts --example demo`).
