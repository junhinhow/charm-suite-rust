# charm-themes

Unified theming system for terminal applications.

Define a color palette once, use it everywhere — lipgloss, bubbles, and any
other component of your TUI.

> **[Read in Portuguese](README.pt-br.md)**

## The Problem

Every styling system asks you to define the same colors again:

- **lipgloss** uses `lipgloss::Style` with inline color definitions
- **bubbles** components each have their own `Styles` struct
- Markdown renderers use their own `StyleConfig`

When building a TUI app, you end up defining the same colors three or more
times in different formats. Changing your theme means updating every single
style definition.

## The Solution

```rust
use charm_themes::themes;

// Pick a theme
let theme = themes::dracula();

// Use it with lipgloss — ready-made semantic styles
let styles = theme.lipgloss();
println!("{}", styles.title.render("Hello"));
println!("{}", styles.error.render("Something went wrong"));
println!("{}", styles.border.render("Boxed content"));

// Or use the semantic colors directly in custom styles
let custom = lipgloss::Style::new()
    .foreground(theme.primary.to_lipgloss())
    .background(theme.background.to_lipgloss());
println!("{}", custom.render("Custom style"));
```

Every theme is also reachable by name:

```rust
use charm_themes::themes;

let all = themes::themes();
assert_eq!(all.len(), 5);
assert!(all.contains_key("tokyo-night"));
```

## Theme Structure

```rust
pub struct Theme {
    pub name: String,
    pub background: Rgb,   // main background
    pub foreground: Rgb,   // main text
    pub primary: Rgb,      // titles, headings
    pub secondary: Rgb,    // subtitles, secondary info
    pub accent: Rgb,       // highlights, emphasis
    pub success: Rgb,      // green / positive
    pub warning: Rgb,      // yellow / caution
    pub error: Rgb,        // red / negative
    pub info: Rgb,         // blue / informational
    pub muted: Rgb,        // gray / disabled
    pub syntax: SyntaxColors, // syntax highlighting
}
```

`Rgb` comes from [`charm-core`](https://crates.io/crates/charm-core) and is the
canonical color type of the Charm Suite. It converts to and from
`lipgloss::Color` through `to_lipgloss()` and `from_lipgloss_str()`.

## Pre-built Lipgloss Styles

```rust
let styles = charm_themes::themes::gruvbox().lipgloss();

styles.base;        // normal text
styles.bold;        // bold
styles.italic;      // italic
styles.faint;       // dimmed

styles.success;     // success message
styles.warning;     // warning
styles.error;       // error
styles.info;        // info

styles.title;       // title (primary, bold)
styles.subtitle;    // subtitle (secondary)
styles.highlight;   // highlight (accent, bold)
styles.border;      // rounded box
styles.code;        // inline code
```

## Syntax Colors

Each theme also carries a palette for code highlighting:

```rust
use charm_themes::themes;

let syntax = themes::nord().syntax;
assert_eq!(syntax.keyword.to_hex(), "#81a1c1");
assert_eq!(syntax.string.to_hex(), "#a3be8c");
```

## Parity with the Go original

The colors are **never typed by hand**. They are extracted programmatically from
the original Go source (`reference/go/charm-themes/themes.go`) by
`scripts/extract-themes.ps1`, and the parity test compares the Rust output
against a golden file generated by the Go implementation:

```text
cargo run -p charm-parity --bin parity -- gen \
    crates/charm-themes/tests/golden/themes.txt -- \
    go run ./reference/go/charm-themes/cmd/parity
```
