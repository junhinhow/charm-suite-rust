# charm-router

Screen stack for Bubble Tea v2: push/pop navigation, exit guards, typed params and a resize-safe breadcrumb.

## Install

```toml
[dependencies]
charm-router = { git = "https://forgejo.multiservidores.com.br/ajr/CharmSuite-Rust", tag = "v0.1.0" }
```
