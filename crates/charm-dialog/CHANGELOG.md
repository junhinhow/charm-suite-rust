# Changelog

All notable changes to this crate are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0]

### Added

- `Dialog` type with the public fields `title`, `message`, `buttons`,
  `selected`, `r#type`, `input_value`, `input_prompt` and `styles`, ported from
  the Go `Dialog` struct.
- `DialogType` enum (`Confirm`, `Alert`, `Input`, `Custom`).
- `Styles` struct and its `Default` implementation, with the same colors as the
  Go `DefaultStyles()`.
- Constructors `Dialog::new_confirm`, `new_alert`, `new_input` and `new_custom`.
- `with_styles`, `next_button`, `prev_button` and `selected_button`, with the
  same edge behaviour as the Go original.
- `render` and `render_overlay`, with golden-file parity tests generated by the
  Go original (`reference/go/charm-dialog/cmd/parity`).
- Runnable demo in `examples/charm_dialog_demo.rs`.
- English and Portuguese (`pt-BR`) documentation.
